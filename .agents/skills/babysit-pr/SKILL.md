# babysit-pr

引数: PR 番号。

1. `gh pr checks <番号>` と `gh pr view <番号> --comments` で、CI の結果と新しいレビューコメントを見る
2. CI が落ちていたら、`gh run view <ID> --log-failed` で原因を読み、直して push する（直し方に判断が要るなら直さずに PR にコメントで質問する）
3. レビューの指摘（Codex の自動レビュー・人のコメント）に対応する。対応しないものは理由を返信する
4. 終わる条件: CI がすべて通り、未対応の指摘がない → 「マージできる状態です」と報告して、ループを止めるよう伝える
5. 同じ CI の失敗を2回直せなかったら、それ以上は直さずに PR に状況をコメントして止める
