# db-migration

1. **先に計画を出して人の承認をもらう**: 足す・変えるテーブルと列、既存データへの影響、戻し方
2. `packages/db/src/schema.ts` を変える
3. `pnpm db:generate` でマイグレーションを作る。生成された SQL を読み、意図どおりか確かめる
4. 既存のマイグレーションファイルは編集しない
5. テストは PGlite に新しいマイグレーションが自動で適用されるので、そのまま `pnpm test` で確かめられる
6. PR に「生成された SQL」と「戻し方」を書く
