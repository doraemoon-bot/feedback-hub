# pr-evidence

`.github/pull_request_template.md` の見出しに沿って書く。

- **何を・なぜ**: 1〜3行。関係する Issue（`Closes #番号`）
- **完了条件と証拠**: Issue の完了条件を1つずつ、満たしたことを示す証拠（テスト名、コマンドの出力）と並べる
- **変えなかったこと**: 触っていないが関係しそうな場所、わざとやらなかったこと
- **見てほしい点**: 判断に迷った箇所、仕様のあいまいさ
- テストの期待値を変えたなら、その理由
