# tdd-fix

1. 再現条件を1文で書く（「○○すると、△△になるはずが□□になる」）。分からなければ止まって聞く
2. 再現するテストを、いちばん近いテストファイルに足す（API なら `apps/api/test/`）
3. `pnpm test` を実行し、**足したテストが、想定どおりの理由で落ちる**ことを確かめる。落ちなければ再現条件を見直す
4. 最小の修正で通す。関係ない場所は触らない
5. `pnpm check` を実行して全部通ることを確かめる
6. 報告: 原因（1〜2文）、足したテストの名前、`pnpm check` の結果の最後の数行、触らなかったが関係しそうな場所
