# 0001. pnpm workspaces ＋ Turborepo のモノレポにする

- 状態: 採用
- 日付: 2026-10-29

## 背景
画面（Next.js）と API（Hono）を同じチームで作る。入力の形や型を両方で共有したい。将来、API を別サービスに切り出す可能性がある。

## 決定
1つのリポジトリに `apps/*`（デプロイ単位）と `packages/*`（共有コード）を置く。タスクの実行は Turborepo に任せる。

## 結果
- 型（`packages/shared` と API の `AppType`）が変わると、使う側の型チェックがすぐ落ちる。人にも AI にも、壊したことがすぐ分かる
- アプリ同士の依存の向きを守る必要がある（`packages` は `apps` を import しない、など）。ルールは自動で確かめる
