# 状態の置き場所

エージェントは会話をまたいで記憶を持てない。**次に作業する誰か（人・エージェント・次の周回）が困らないよう、状態は会話の外に置く**。
置き場所を決めておかないと、同じ作業の繰り返しや、数日前に見送った案の再提案が起きる。

| 状態 | 置き場所 | 書く | 読む | いつ消す |
|---|---|---|---|---|
| やること・進み具合 | Issue とラベル（`triage` → `agent:ready` → `agent:working` → PR → close） | 人・仕分け役・ループ | 全員 | Issue を閉じたら終わり |
| 決めたこと | `docs/adr/`、`AGENTS.md` | **人** | 毎回のエージェント | 古くなったら人が直す（ADR は「廃止」にして残す） |
| 作業の記録・申し送り | Issue のコメント（下の形） | エージェント | 次に作業する人・エージェント | 残す（履歴） |
| 人への質問 | Issue のコメント ＋ `needs-human` ラベル | エージェント | 人 | 答えたらラベルを外す |
| 証拠 | PR の本文（テンプレート）、CI の結果 | エージェント・CI | レビューする人 | 残す |
| ループの実行履歴 | GitHub Actions の実行記録、Issue のコメント | ループ | ループの責任者 | Actions の保存期間（既定 90 日） |
| 学び | `LEARNINGS.md` | 人（案はエージェント） | ハーネスを直す人 | ルールに反映したら「反映済み」 |

## コメントの形

作業の記録（エージェントが作業を終えたとき・止まったとき）:

```
🤖 作業記録
- やったこと:
- 証拠: （テスト名、pnpm check の結果、PR）
- 止まった理由: （完了 / 上限 / 人の判断が必要 / 失敗が続いた）
- 次にやること・申し送り:
```

人への質問（`needs-human` を付けて止まるとき）:

```
🙋 人の判断が必要です
- 状況:
- 質問:
- 選択肢と推奨: A（推奨）… / B …
```
