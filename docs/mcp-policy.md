# MCP の接続方針

MCP は「AI に外部の道具を持たせる」仕組みであると同時に、**社内の情報を読む経路と、外へ書き込む経路**にもなる。
接続先は個人の好みで足さず、チームとしてここで決めたものだけを `.mcp.json`（Claude Code）と `.codex/config.toml`（Codex）に置く。

| 接続先 | 用途 | 権限 | 理由・注意 |
|---|---|---|---|
| GitHub（公式のリモート MCP） | Issue・PR・CI の結果を読む | **読み取りのみ**（`X-MCP-Readonly`）。使う道具は issues / pull_requests / actions だけ | 書き込み（コメント・ラベル）は `gh` コマンドで行い、権限設定の `ask` で人が確認する。公開リポジトリなので、**書き込み権限のない人が書いた内容は読ませない**（`X-MCP-Lockdown`。Issue に仕込まれた指示に AI が従う事故を防ぐ） |
| Playwright | 画面を実際に操作して確かめる | 手元の使い捨てブラウザ（`--isolated`） | 外部サイトの操作には使わない。版を固定している |

## 足したいとき

1. この表に1行足す PR を出す（用途・権限・読む情報と書く先・信頼できない入力が入るか）
2. ハーネス担当（CODEOWNERS）のレビューを通す
3. 書き込みのできる道具は、読み取りで足りないか先に検討する

## 認証

- GitHub: 読み取り専用の fine-grained personal access token を各自が発行し、環境変数 `GITHUB_MCP_PAT` に入れる（リポジトリには置かない）
